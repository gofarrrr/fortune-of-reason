# The Fortune of Reason — Dekalog poznawczy pracy z AI

An interactive 3D WebGL experience featuring ten fortune cookies on a ceramic tray. Grounded in peer-reviewed cognitive science papers and distilled through the craftsman philosophy of Kevin Kelly (*Excellent Advice for Living*).

Built as an experimental demonstration of Three.js r170, procedural texturing, and Web Audio API synthesis in a single, zero-dependency, self-contained architecture.

## 🛠 Tech Stack

- **Three.js r170**: Procedural ceramic tray, fortune cookie parametric geometry, dynamic shadows, and cracking physics.
- **GSAP 3.12**: Fluid camera motions, ribbon unfolding, and micro-interactions.
- **Web Audio API**: Procedural cookie snap and paper rustle synthesis (no external MP3/WAV files).
- **Zero Assets**: 100% self-contained single-file HTML (`index.html`).
